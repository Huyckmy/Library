Getting Started

Load the library and create your main window in seconds.

-- Load library from repository local bearlib = loadstring(game:HttpGet("https://raw.githubusercontent.com/Huyckmy/Library/refs/heads/Ui_OS/bearlib.lua"))() -- Create main window local win = bearlib:MakeWindow({ "My Awesome Hub", -- Title "by YourName", -- Subtitle "flags.json" -- Auto-save flags file })
The third parameter is the JSON filename for auto-saving toggle, slider, and dropdown states.
📁

Tabs and Sections

Organize your UI with tabs and sections for clarity.

-- Create a new tab local mainTab = win:MakeTab({ "Main", "rbxassetid://10709791437" -- Icon (optional) }) -- Add a section to group components local sec = mainTab:AddSection("Settings")
Sections help organize related UI elements within a tab.
🎛️

UI Components

All available elements: Button, Toggle, Slider, Dropdown, TextBox, Profile, Discord Cards, and more.

-- Button mainTab:AddButton({ "Click Me", function() print("Hello!") end }) -- Toggle with auto-save flag mainTab:AddToggle({ "Auto Farm", true, nil, "auto_farm" })
Use Flags to persist state across script executions.

UI Components Reference

Detailed usage for each element in Bear Library.

Button

Clickable button with title, description, and callback.

local btn = tab:AddButton({ "Execute", -- Title "Run the main script", -- Description function() -- Callback print("Executed!") end, "exec_flag" -- Flag (optional) }) -- Available methods btn:Set("New Title", "New Description") btn:Visible(false) -- Hide button btn:Destroy() -- Remove button

Toggle

On/off switch with automatic flag saving.

local tog = tab:AddToggle({ "Auto Reconnect", -- Title false, -- Default value function(v) -- Callback on change print("Reconnect:", v) end, "reconnect" -- Flag for saving }) -- Change value via code tog:Set(true) -- Read value from flag print(bearlib.Flags.reconnect)
Flags are automatically saved to the JSON file on every change.

Slider

Numeric slider with min, max, step, and default value.

local sld = tab:AddSlider({ "Speed", -- Title "Movement speed", -- Description 1, 100, -- Min, Max 1, -- Step increment 50, -- Default value function(v) -- Callback print("Speed:", v) end, "speed" -- Flag }) -- Set new value sld:Set(75)

Dropdown

Single or multi-select dropdown with search and flags.

local ddown = tab:AddDropdown({ "Server", -- Title { "EU", "US", "AS" }, -- Options list "US", -- Default value function(v) -- Callback print("Selected:", v) end, "server", -- Flag true -- MultiSelect (allow multiple) }) -- Add new option ddown:Add("AU") -- Select option ddown:Select("EU")

TextBox

Text input with placeholder, clear-on-focus, and callback.

local tb = tab:AddTextBox({ "Username", -- Title "Player1", -- Default value false, -- Clear on focus function(t) -- Callback on focus lost print("Input:", t) end, "Enter name..." -- Placeholder }) -- Real-time input processing tb.OnChanging = function(t) return string.upper(t) -- Auto uppercase end

Profile

Display user info with avatar, cover image, and bio.

local prof = tab:AddProfile({ "Quang Huy", -- Name "Lua Developer", -- Bio Avatar = "rbxassetid://123", Cover = "rbxassetid://456", Verified = true }) -- Update information prof:SetBio("New bio here") prof:SetBorderColor(Color3.fromRGB(255,200,100))

Discord Card

Single Discord server card with invite link.

local dc = tab:AddSingleDiscordCard({ Title = "Bear Community", Description = "Support and Updates", Logo = "rbxassetid://...", BannerColor = Color3.fromRGB(88,101,242), Online = 42, Members = 1280, Invite = "https://discord.gg/...", Verified = true }) -- Update card dc:SetTitle("New Server") dc:SetStats(99, 2000) dc:SetInviteLink("https://discord.gg/new")

Discord Invite (2 Cards)

Two Discord cards side by side.

local inv = tab:AddDiscordInvite({ { "Server 1", "...", "rbxassetid://...", Color3.fromRGB(88,101,242), 10, 100, "https://discord.gg/..." }, { "Server 2", "...", "rbxassetid://...", Color3.fromRGB(255,70,70), 5, 50, "https://discord.gg/..." } }) -- Update individual cards inv:UpdateCard1({ "New Card 1", "...", "rbxassetid://..." }) inv:UpdateCard2({ "New Card 2", "...", "rbxassetid://..." })

Dialog

Confirmation dialog with custom buttons.

local dialog = win:Dialog({ Title = "Confirm", Text = "Do you want to exit?", Options = { { "Exit", function() game:Shutdown() end }, { "Cancel" } } })
Dialog appears on top and blocks interaction with other components.

Top Bar Badges

Display small badges on the window title bar.

-- 5 bars available: Bar, Bar2, Bar3, Bar4, Bar5 win:Bar("Online", Color3.fromRGB(0,200,0), nil, nil, "rbxassetid://...") win:Bar2("VIP", Color3.fromRGB(200,150,0)) win:Bar3("Beta", Color3.fromRGB(100,100,200)) win:Bar4("v1.2.0") win:Bar5("Bear")
Each bar can customize background, border, text color, and icon.

Tab Group (SubTabs)

Group multiple subtabs under one parent tab with expand/collapse.

-- Create tab group local group = win:MakeTabGroup({ "Game Settings", "rbxassetid://..." -- Icon }) -- Add subtabs local sub1 = group:AddTab({ "General" }) sub1:AddToggle({ "Auto Reconnect", true }) local sub2 = group:AddTab({ "Graphics" }) sub2:AddSlider({ "FPS", 30, 240, 1, 60 }) local sub3 = group:AddTab({ "Audio" }) sub3:AddButton({ "Test Sound", function() print("Sound test") end }) -- Expand / collapse group:Expand() group:Collapse()
SubTabs function as independent tabs but are grouped under a parent.

Theme and Customization

Change colors, borders, and scale of the UI.

Color Settings

-- Main colors bearlib:SetHubColor(Color3.fromRGB(20,20,40)) bearlib:SetTextColor(Color3.fromRGB(255,255,255)) bearlib:SetStrokeColor(Color3.fromRGB(100,100,200)) -- Border colors for specific components bearlib:SetUIBorderColor(Color3.fromRGB(200,200,255)) bearlib:SetDiscordBorderColor(Color3.fromRGB(150,150,255)) bearlib:SetProfileBorderColor(Color3.fromRGB(255,200,100)) -- Border thickness bearlib:SetBorderThickness(2)

Toggle Colors

-- Get current toggle colors local colors = bearlib:GetToggleColors() print(colors.ToggleOn) -- Reset to defaults bearlib:ResetToggleColors() bearlib:ResetBorderColors()
Reset restores colors to the library's original settings.

Scale and Size

-- Change UI scale (default: 450) bearlib:SetScale(500) -- Window size auto-saves to bearlib.json -- Drag bottom-right corner to resize

Notifications

Show toast notifications with custom icon and duration.

bearlib:Notify({ Title = "Success", Message = "Connected successfully!", Icon = "rbxassetid://...", Duration = 5 -- Seconds })
Notifications auto-queue and display sequentially.

Flags and Persistent Storage

Manage state and auto-save to JSON file.

-- Specify save file when creating window local win = bearlib:MakeWindow({ "My Hub", "by ...", "my_flags.json" -- Auto-save flags }) -- Access flags print(bearlib.Flags.auto_farm) -- Change flag via code bearlib:SetFlag("auto_farm", true) -- Listen to flag changes bearlib.Connection.FlagsChanged:Connect(function(flag, value) print("Flag changed:", flag, value) end) -- Manual save (usually auto-saved) bearlib.Connection:FireConnection("FileSaved")
Flags auto-save on every change with a 0.1s debounce.

Complete Example

-- Load library from repository local bearlib = loadstring(game:HttpGet("https://raw.githubusercontent.com/Huyckmy/Library/refs/heads/Ui_OS/bearlib.lua"))() -- Create main window local win = bearlib:MakeWindow({ "Bear Hub", "by Quang Huy", "hub_flags.json" }) -- Create tabs local mainTab = win:MakeTab({ "Main", "rbxassetid://10709791437" }) local settingsTab = win:MakeTab({ "Settings" }) -- Section and Button local sec = mainTab:AddSection("Controls") mainTab:AddButton({ "Run Script", "Execute main function", function() print("Script executed!") bearlib:Notify({ Title = "Success", Message = "Script executed" }) end }) -- Toggle with flag mainTab:AddToggle({ "Auto Farm", "Enable auto farming", false, function(v) print("Auto Farm:", v) end, "auto_farm" }) -- Slider mainTab:AddSlider({ "Speed", "Adjust movement speed", 1, 20, 0.5, 5, function(v) print("Speed:", v) end, "speed" }) -- Dropdown mainTab:AddDropdown({ "Server", { "NA", "EU", "AS" }, "EU", function(v) print("Server:", v) end, "server" }) -- Profile settingsTab:AddProfile({ "Quang Huy", "Lua Developer and UI Designer", Avatar = "rbxassetid://123456789", Cover = "rbxassetid://987654321", Verified = true }) -- Discord Card settingsTab:AddSingleDiscordCard({ Title = "Bear Community", Description = "Support and updates channel", Logo = "rbxassetid://...", BannerColor = Color3.fromRGB(88, 101, 242), Online = 42, Members = 1280, Invite = "https://discord.gg/...", Verified = true }) -- Badges win:Bar("Online", Color3.fromRGB(0,200,0)) win:Bar2("v1.2.0", Color3.fromRGB(100,100,200)) -- Initial notification bearlib:Notify({ Title = "Bear Hub", Message = "Loaded successfully!", Duration = 3 })

API Reference

Complete list of all functions and methods.

bearlib (Global)

  • MakeWindow()Create main window
  • Notify()Show notification toast
  • SetScale()Change UI scale
  • SetHubColor()Set main background color
  • SetTextColor()Set text color
  • SetStrokeColor()Set stroke/border color
  • SetUIBorderColor()Set window border color
  • SetDiscordBorderColor()Set Discord card border
  • SetProfileBorderColor()Set profile border color
  • SetBorderThickness()Set border thickness
  • GetToggleColors()Get current toggle colors
  • ResetToggleColors()Reset toggle colors to default
  • ResetBorderColors()Reset border colors to default
  • GetFlag()Get flag value
  • SetFlag()Set flag value
  • Connection.FlagsChangedEvent fired when flag changes
  • Connection.FileSavedEvent fired when file is saved

Window (win)

  • MakeTab()Create a new tab
  • MakeTabGroup()Create a tab group with subtabs
  • Dialog()Create a confirmation dialog
  • Bar() / Bar2() ...Add badges to title bar
  • Set()Change window title/subtitle
  • CloseBtn()Close the window
  • MinimizeBtn()Minimize the window
  • SelectTab()Select tab by index or reference

Tab and SubTab

  • AddSection()Add a section header
  • AddButton()Add a button
  • AddToggle()Add a toggle switch
  • AddSlider()Add a numeric slider
  • AddTextBox()Add a text input box
  • AddDropdown()Add a dropdown selector
  • AddProfile()Add a profile card
  • AddSingleDiscordCard()Add a Discord server card
  • AddDiscordInvite()Add two Discord cards side by side
  • Enable() / Disable()Show/hide tab
  • Visible()Toggle visibility
  • Destroy()Remove tab

Element Methods (Common)

  • Set()Change value / title / description
  • Visible()Show/hide element
  • Destroy()Remove element
  • Callback()Trigger callback (if available)
