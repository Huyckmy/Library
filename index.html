Bắt đầu nhanh

Tạo cửa sổ chính và thêm các thành phần UI chỉ với vài dòng code.

local win = bearlib:MakeWindow({ "Bear Hub", "by Quang Huy", "flags.json" })
📁

Tab & Section

Tổ chức giao diện với các tab và section rõ ràng.

local tab = win:MakeTab({ "Cài đặt", "rbxassetid://123" }) local section = tab:AddSection("Tùy chỉnh")
🎛️

Thành phần đa dạng

Button, Toggle, Slider, Dropdown, TextBox, Profile, Discord Cards,...

tab:AddButton({ "Click me", function() print("Hello!") end }) tab:AddToggle({ "Auto Farm", true })

📦 Các thành phần UI

Chi tiết cách sử dụng từng loại element trong Bear Library.

🔘 Button

Nút bấm với tiêu đề, mô tả và callback.

local btn = tab:AddButton({ "Tiêu đề", "Mô tả", function() print("Đã bấm!") end, "flag_name" -- optional }) -- Các method btn:Set("Tên mới", "Mô tả mới") btn:Visible(false) btn:Destroy()

🔁 Toggle

Công tắc bật/tắt với flag lưu trạng thái.

local tog = tab:AddToggle({ "Auto Farm", true, -- default function(v) print(v) end, "auto_farm" -- flag }) -- Set value tog:Set(false) -- Lấy giá trị print(bearlib.Flags.auto_farm)

📊 Slider

Thanh trượt với giá trị số học.

local sld = tab:AddSlider({ "Tốc độ", 1, 100, -- min, max 1, -- step 50, -- default function(v) print(v) end, "speed" -- flag }) sld:Set(75) -- thay đổi giá trị

📋 Dropdown

Chọn một hoặc nhiều tùy chọn từ danh sách.

local ddown = tab:AddDropdown({ "Chọn server", { "EU", "US", "AS" }, "US", -- default function(v) print(v) end, "server", -- flag true -- MultiSelect }) ddown:Add("AU") -- thêm option ddown:Select("EU")

✏️ TextBox

Ô nhập văn bản với callback khi focus mất.

local tb = tab:AddTextBox({ "Tên", "Player1", -- default false, -- clear on focus function(t) print(t) end, "Nhập tên..." -- placeholder }) tb.OnChanging = function(t) return string.upper(t) end

👤 Profile

Hiển thị thông tin người dùng với avatar, cover, bio.

local prof = tab:AddProfile({ "Quang Huy", "Dev & Designer", Avatar = "rbxassetid://...", Cover = "rbxassetid://...", Verified = true }) prof:SetBio("New bio") prof:SetBorderColor(Color3.fromRGB(255,200,100))

💬 Discord Card

Card hiển thị server Discord với link mời.

local dc = tab:AddSingleDiscordCard({ Title = "Bear Community", Description = "Kênh hỗ trợ & cập nhật", Logo = "rbxassetid://...", BannerColor = Color3.fromRGB(88,101,242), Online = 42, Members = 1280, Invite = "https://discord.gg/...", Verified = true }) dc:SetTitle("New Server") dc:SetStats(99, 2000)

📨 Discord Invite (2 cards)

Hiển thị 2 card Discord cạnh nhau.

local inv = tab:AddDiscordInvite({ { "Server 1", "...", "rbxassetid://...", Color3.fromRGB(88,101,242), 10, 100, "https://discord.gg/..." }, { "Server 2", "...", "rbxassetid://...", Color3.fromRGB(255,70,70), 5, 50, "https://discord.gg/..." } }) inv:UpdateCard1({ "New Card 1", "...", "rbxassetid://..." })

💬 Dialog

Hộp thoại xác nhận với các nút tùy chỉnh.

local dialog = win:Dialog({ Title = "Xác nhận", Text = "Bạn có muốn thoát?", Options = { { "Thoát", function() game:Shutdown() end }, { "Hủy" } } })

🏷️ Bar (Badge)

Hiển thị các badge nhỏ trên thanh tiêu đề.

win:Bar("Online", Color3.fromRGB(0,200,0), nil, nil, "rbxassetid://...") win:Bar2("VIP", Color3.fromRGB(200,150,0)) win:Bar3("Beta", Color3.fromRGB(100,100,200)) win:Bar4("v1.2.0") win:Bar5("🐻")

📂 Tab Group (SubTab)

Nhóm các tab con dưới một tab cha, có thể mở rộng/thu gọn.

local group = win:MakeTabGroup({ "🎮 Game Settings", "rbxassetid://..." -- icon }) local sub1 = group:AddTab({ "General" }) sub1:AddToggle({ "Auto Reconnect", true }) local sub2 = group:AddTab({ "Graphics" }) sub2:AddSlider({ "FPS", 30, 240, 1, 60 }) local sub3 = group:AddTab({ "Audio" }) sub3:AddButton({ "Test Sound", function() print("🔊") end }) -- Mở rộng/thu gọn group:Expand() group:Collapse()

🎨 Tùy chỉnh giao diện

Các hàm thay đổi màu sắc và border của UI.

🌈 Màu sắc

bearlib:SetHubColor(Color3.fromRGB(20,20,40)) bearlib:SetTextColor(Color3.fromRGB(255,255,255)) bearlib:SetStrokeColor(Color3.fromRGB(100,100,200)) bearlib:SetUIBorderColor(Color3.fromRGB(200,200,255)) bearlib:SetDiscordBorderColor(Color3.fromRGB(150,150,255)) bearlib:SetProfileBorderColor(Color3.fromRGB(255,200,100)) bearlib:SetBorderThickness(2)

🔁 Toggle Colors

-- Lấy màu hiện tại local colors = bearlib:GetToggleColors() print(colors.ToggleOn) -- Reset về mặc định bearlib:ResetToggleColors() bearlib:ResetBorderColors()

📐 Scale & Kích thước

-- Thay đổi tỉ lệ UI (mặc định 450) bearlib:SetScale(500) -- Lưu kích thước cửa sổ tự động -- File: bearlib.json

🔔 Notifications

bearlib:Notify({ Title = "Thông báo", Message = "Đã kết nối thành công!", Icon = "rbxassetid://...", Duration = 5 })

💾 Flags & Lưu trữ

Quản lý trạng thái và tự động lưu vào file JSON.

-- Khi tạo cửa sổ, truyền tên file lưu local win = bearlib:MakeWindow({ "My Hub", "by ...", "my_flags.json" -- tự động lưu flags }) -- Truy cập flags print(bearlib.Flags.auto_farm) -- Thay đổi flag bằng code bearlib:SetFlag("auto_farm", true) -- Lắng nghe sự kiện flags thay đổi bearlib.Connection.FlagsChanged:Connect(function(flag, value) print("Flag changed:", flag, value) end) -- Lưu manual bearlib.Connection:FireConnection("FileSaved")

📝 Ví dụ đầy đủ

local bearlib = loadstring(game:HttpGet("https://raw.githubusercontent.com/.../bearlib.lua"))() local win = bearlib:MakeWindow({ "🐻 Bear Hub", "by Quang Huy", "hub_flags.json" }) local mainTab = win:MakeTab({ "Chính", "rbxassetid://10709791437" }) local settingsTab = win:MakeTab({ "Cài đặt" }) -- Section & Button local sec = mainTab:AddSection("Điều khiển") mainTab:AddButton({ "Chạy script", "Kích hoạt tính năng chính", function() print("✅ Script đã chạy!") bearlib:Notify({ Title = "Thành công", Message = "Script đã được kích hoạt" }) end }) -- Toggle mainTab:AddToggle({ "Auto Farm", "Tự động farm khi vào game", false, function(v) print("Auto Farm:", v) end, "auto_farm" }) -- Slider mainTab:AddSlider({ "Tốc độ", "Điều chỉnh tốc độ di chuyển", 1, 20, 0.5, 5, function(v) print("Tốc độ:", v) end, "speed" }) -- Dropdown mainTab:AddDropdown({ "Server", { "NA", "EU", "AS" }, "EU", function(v) print("Server:", v) end, "server" }) -- Profile settingsTab:AddProfile({ "Quang Huy", "Lua Developer & UI Designer", Avatar = "rbxassetid://123456789", Cover = "rbxassetid://987654321", Verified = true }) -- Discord Card settingsTab:AddSingleDiscordCard({ Title = "Bear Community", Description = "Kênh hỗ trợ và cập nhật mới nhất", Logo = "rbxassetid://...", BannerColor = Color3.fromRGB(88, 101, 242), Online = 42, Members = 1280, Invite = "https://discord.gg/...", Verified = true }) -- Badge win:Bar("Online", Color3.fromRGB(0,200,0)) win:Bar2("v1.2.0", Color3.fromRGB(100,100,200)) -- Notification bearlib:Notify({ Title = "🚀 Bear Hub", Message = "Đã tải thành công!", Duration = 3 })

📚 API Reference

Danh sách các hàm và method có sẵn.

🔹 bearlib (Global)

  • MakeWindow()Tạo cửa sổ chính
  • Notify()Hiển thị thông báo
  • SetScale()Thay đổi tỉ lệ UI
  • SetHubColor()Màu nền chính
  • SetTextColor()Màu chữ
  • SetStrokeColor()Màu viền
  • SetUIBorderColor()Màu viền cửa sổ
  • SetDiscordBorderColor()Màu viền Discord card
  • SetProfileBorderColor()Màu viền Profile
  • SetBorderThickness()Độ dày viền
  • GetToggleColors()Lấy màu toggle
  • ResetToggleColors()Reset màu toggle
  • ResetBorderColors()Reset màu viền
  • GetFlag()Lấy giá trị flag
  • SetFlag()Set giá trị flag
  • Connection.FlagsChangedEvent khi flag thay đổi
  • Connection.FileSavedEvent khi file được lưu

🔸 Window (win)

  • MakeTab()Tạo tab mới
  • MakeTabGroup()Tạo nhóm tab (SubTab)
  • Dialog()Tạo hộp thoại
  • Bar() / Bar2() ...Badge trên thanh tiêu đề
  • Set()Đổi tên cửa sổ
  • CloseBtn()Đóng cửa sổ
  • MinimizeBtn()Thu nhỏ cửa sổ
  • SelectTab()Chọn tab theo index hoặc tên

🔹 Tab & SubTab

  • AddSection()Thêm section
  • AddButton()Thêm nút bấm
  • AddToggle()Thêm toggle
  • AddSlider()Thêm slider
  • AddTextBox()Thêm textbox
  • AddDropdown()Thêm dropdown
  • AddProfile()Thêm profile card
  • AddSingleDiscordCard()Thêm 1 Discord card
  • AddDiscordInvite()Thêm 2 Discord card
  • AddDiscordInviteOld()Phiên bản cũ
  • Enable() / Disable()Hiển thị/ẩn tab
  • Visible()Ẩn/hiện tab
  • Destroy()Xóa tab

🔸 Element Methods (chung)

  • Set()Thay đổi giá trị / tiêu đề / mô tả
  • Visible()Ẩn/hiện element
  • Destroy()Xóa element
  • Callback()Gọi callback (nếu có)
