Getting Started

Load the library and create your main window in seconds.

-- 📥 Tải thư viện từ repository local bearlib = loadstring(game:HttpGet("https://raw.githubusercontent.com/Huyckmy/Library/refs/heads/Ui_OS/bearlib.lua"))() -- 🪟 Tạo cửa sổ chính local win = bearlib:MakeWindow({ "My Awesome Hub", -- Tiêu đề "by YourName", -- Phụ đề "flags.json" -- File lưu flags (tự động) })
💡 Gợi ý: Tham số thứ 3 là tên file JSON để tự động lưu trạng thái toggle, slider, dropdown.
📁

Tabs & Sections

Organize your UI with tabs and sections for clarity.

-- 📑 Tạo tab mới local mainTab = win:MakeTab({ "Main", "rbxassetid://10709791437" -- Icon (optional) }) -- 📂 Thêm section để nhóm các thành phần local sec = mainTab:AddSection("⚙️ Settings")
📌 Chú thích: Section giúp phân chia rõ ràng các nhóm chức năng trong tab.

UI Components

All available elements: Button, Toggle, Slider, Dropdown, TextBox, Profile, Discord Cards, and more.

-- 🔘 Button mainTab:AddButton({ "Click Me", function() print("Hello!") end }) -- 🔁 Toggle với flag tự động lưu mainTab:AddToggle({ "Auto Farm", true, nil, "auto_farm" })
🧠 Mẹo: Sử dụng Flags để lưu trạng thái và đồng bộ giữa các lần chạy script.

📦 UI Components Reference

Detailed usage for each element in Bear Library.

🔘 Button

Clickable button with title, description, and callback.

local btn = tab:AddButton({ "Execute", -- Tiêu đề "Run the main script", -- Mô tả function() -- Callback print("✅ Executed!") end, "exec_flag" -- Flag (optional) }) -- 📝 Các method hỗ trợ btn:Set("New Title", "New Description") btn:Visible(false) -- Ẩn button btn:Destroy() -- Xóa button

🔁 Toggle

On/off switch with automatic flag saving.

local tog = tab:AddToggle({ "Auto Reconnect", -- Tiêu đề false, -- Giá trị mặc định function(v) -- Callback khi thay đổi print("Reconnect:", v) end, "reconnect" -- Flag để lưu }) -- 🔄 Thay đổi giá trị bằng code tog:Set(true) -- 📖 Đọc giá trị từ flag print(bearlib.Flags.reconnect)
💾 Flag tự động được lưu vào file JSON mỗi khi thay đổi.

📊 Slider

Numeric slider with min, max, step, and default value.

local sld = tab:AddSlider({ "Speed", -- Tiêu đề "Movement speed", -- Mô tả 1, 100, -- Min, Max 1, -- Step (bước nhảy) 50, -- Giá trị mặc định function(v) -- Callback print("Speed:", v) end, "speed" -- Flag }) -- 🎯 Set giá trị mới sld:Set(75)

📋 Dropdown

Single or multi-select dropdown with search and flags.

local ddown = tab:AddDropdown({ "Server", -- Tiêu đề { "EU", "US", "AS" }, -- Danh sách options "US", -- Giá trị mặc định function(v) -- Callback print("Selected:", v) end, "server", -- Flag true -- MultiSelect (chọn nhiều) }) -- ➕ Thêm option mới ddown:Add("AU") -- 🎯 Chọn option ddown:Select("EU")

✏️ TextBox

Text input with placeholder, clear-on-focus, and callback.

local tb = tab:AddTextBox({ "Username", -- Tiêu đề "Player1", -- Giá trị mặc định false, -- Clear on focus function(t) -- Callback khi mất focus print("Input:", t) end, "Enter name..." -- Placeholder }) -- 🔄 Xử lý input real-time tb.OnChanging = function(t) return string.upper(t) -- Tự động viết hoa end

👤 Profile

Display user info with avatar, cover image, and bio.

local prof = tab:AddProfile({ "Quang Huy", -- Tên "Lua Developer", -- Bio Avatar = "rbxassetid://123", Cover = "rbxassetid://456", Verified = true }) -- ✏️ Cập nhật thông tin prof:SetBio("New bio here") prof:SetBorderColor(Color3.fromRGB(255,200,100))

💬 Discord Card

Single Discord server card with invite link.

local dc = tab:AddSingleDiscordCard({ Title = "Bear Community", Description = "Support & Updates", Logo = "rbxassetid://...", BannerColor = Color3.fromRGB(88,101,242), Online = 42, Members = 1280, Invite = "https://discord.gg/...", Verified = true }) -- 🔄 Cập nhật dc:SetTitle("New Server") dc:SetStats(99, 2000) dc:SetInviteLink("https://discord.gg/new")

📨 Discord Invite (2 Cards)

Two Discord cards side by side.

local inv = tab:AddDiscordInvite({ { "Server 1", "...", "rbxassetid://...", Color3.fromRGB(88,101,242), 10, 100, "https://discord.gg/..." }, { "Server 2", "...", "rbxassetid://...", Color3.fromRGB(255,70,70), 5, 50, "https://discord.gg/..." } }) -- 🔄 Cập nhật từng card inv:UpdateCard1({ "New Card 1", "...", "rbxassetid://..." }) inv:UpdateCard2({ "New Card 2", "...", "rbxassetid://..." })

💬 Dialog

Confirmation dialog with custom buttons.

local dialog = win:Dialog({ Title = "Confirm", Text = "Do you want to exit?", Options = { { "Exit", function() game:Shutdown() end }, { "Cancel" } } })
⚠️ Dialog tự động hiển thị trên cùng và chặn tương tác với các thành phần khác.

🏷️ Top Bar Badges

Display small badges on the window title bar.

-- Có 5 thanh bar: Bar, Bar2, Bar3, Bar4, Bar5 win:Bar("Online", Color3.fromRGB(0,200,0), nil, nil, "rbxassetid://...") win:Bar2("VIP", Color3.fromRGB(200,150,0)) win:Bar3("Beta", Color3.fromRGB(100,100,200)) win:Bar4("v1.2.0") win:Bar5("🐻")
🎨 Mỗi bar có thể tùy chỉnh màu nền, màu viền, màu chữ và icon.

📂 Tab Group (SubTabs)

Group multiple subtabs under one parent tab with expand/collapse.

-- 📁 Tạo group tab local group = win:MakeTabGroup({ "🎮 Game Settings", "rbxassetid://..." -- Icon }) -- 📑 Thêm subtab local sub1 = group:AddTab({ "General" }) sub1:AddToggle({ "Auto Reconnect", true }) local sub2 = group:AddTab({ "Graphics" }) sub2:AddSlider({ "FPS", 30, 240, 1, 60 }) local sub3 = group:AddTab({ "Audio" }) sub3:AddButton({ "Test Sound", function() print("🔊") end }) -- 🔽 Mở rộng / thu gọn group:Expand() group:Collapse()
📌 SubTab hoạt động như một tab độc lập nhưng nằm gọn trong group cha.

🎨 Theme & Customization

Change colors, borders, and scale of the UI.

🌈 Color Settings

-- 🎨 Thay đổi màu sắc chính bearlib:SetHubColor(Color3.fromRGB(20,20,40)) bearlib:SetTextColor(Color3.fromRGB(255,255,255)) bearlib:SetStrokeColor(Color3.fromRGB(100,100,200)) -- 🖌️ Màu viền cho từng thành phần bearlib:SetUIBorderColor(Color3.fromRGB(200,200,255)) bearlib:SetDiscordBorderColor(Color3.fromRGB(150,150,255)) bearlib:SetProfileBorderColor(Color3.fromRGB(255,200,100)) -- 📏 Độ dày viền bearlib:SetBorderThickness(2)

🔁 Toggle Colors

-- 📖 Lấy màu toggle hiện tại local colors = bearlib:GetToggleColors() print(colors.ToggleOn) -- 🔄 Reset về mặc định bearlib:ResetToggleColors() bearlib:ResetBorderColors()
🔄 Reset sẽ đưa các màu về thiết lập gốc của thư viện.

📐 Scale & Size

-- 🔍 Thay đổi tỉ lệ UI (mặc định: 450) bearlib:SetScale(500) -- 💾 Kích thước cửa sổ tự động lưu vào bearlib.json -- Bạn có thể kéo góc dưới phải để thay đổi kích thước

🔔 Notifications

Show toast notifications with custom icon and duration.

bearlib:Notify({ Title = "Success", Message = "Connected successfully!", Icon = "rbxassetid://...", Duration = 5 -- Giây })
🔔 Notification tự động xếp hàng và hiển thị lần lượt.

💾 Flags & Persistent Storage

Manage state and auto-save to JSON file.

-- 📁 Khai báo file lưu khi tạo cửa sổ local win = bearlib:MakeWindow({ "My Hub", "by ...", "my_flags.json" -- Tự động lưu flags }) -- 📖 Truy cập flags print(bearlib.Flags.auto_farm) -- ✏️ Thay đổi flag bằng code bearlib:SetFlag("auto_farm", true) -- 👂 Lắng nghe sự kiện flag thay đổi bearlib.Connection.FlagsChanged:Connect(function(flag, value) print("Flag changed:", flag, value) end) -- 💾 Lưu manual (thường không cần vì tự động) bearlib.Connection:FireConnection("FileSaved")
💡 Flag tự động được lưu mỗi khi giá trị thay đổi (có debounce 0.1s).

📝 Complete Example

-- 📥 Load thư viện từ repository local bearlib = loadstring(game:HttpGet("https://raw.githubusercontent.com/Huyckmy/Library/refs/heads/Ui_OS/bearlib.lua"))() -- 🪟 Tạo cửa sổ chính local win = bearlib:MakeWindow({ "🐻 Bear Hub", "by Quang Huy", "hub_flags.json" }) -- 📑 Tạo tabs local mainTab = win:MakeTab({ "Main", "rbxassetid://10709791437" }) local settingsTab = win:MakeTab({ "Settings" }) -- 📂 Section & Button local sec = mainTab:AddSection("Controls") mainTab:AddButton({ "Run Script", "Execute main function", function() print("✅ Script executed!") bearlib:Notify({ Title = "Success", Message = "Script executed" }) end }) -- 🔁 Toggle với flag mainTab:AddToggle({ "Auto Farm", "Enable auto farming", false, function(v) print("Auto Farm:", v) end, "auto_farm" }) -- 📊 Slider mainTab:AddSlider({ "Speed", "Adjust movement speed", 1, 20, 0.5, 5, function(v) print("Speed:", v) end, "speed" }) -- 📋 Dropdown mainTab:AddDropdown({ "Server", { "NA", "EU", "AS" }, "EU", function(v) print("Server:", v) end, "server" }) -- 👤 Profile settingsTab:AddProfile({ "Quang Huy", "Lua Developer & UI Designer", Avatar = "rbxassetid://123456789", Cover = "rbxassetid://987654321", Verified = true }) -- 💬 Discord Card settingsTab:AddSingleDiscordCard({ Title = "Bear Community", Description = "Support & updates channel", Logo = "rbxassetid://...", BannerColor = Color3.fromRGB(88, 101, 242), Online = 42, Members = 1280, Invite = "https://discord.gg/...", Verified = true }) -- 🏷️ Badges win:Bar("Online", Color3.fromRGB(0,200,0)) win:Bar2("v1.2.0", Color3.fromRGB(100,100,200)) -- 🔔 Notification khởi tạo bearlib:Notify({ Title = "🚀 Bear Hub", Message = "Loaded successfully!", Duration = 3 })

📚 API Reference

Complete list of all functions and methods.

🔹 bearlib (Global)

  • MakeWindow()Create main window
  • Notify()Show notification toast
  • SetScale()Change UI scale
  • SetHubColor()Set main background color
  • SetTextColor()Set text color
  • SetStrokeColor()Set stroke/border color
  • SetUIBorderColor()Set window border color
  • SetDiscordBorderColor()Set Discord card border
  • SetProfileBorderColor()Set profile border color
  • SetBorderThickness()Set border thickness
  • GetToggleColors()Get current toggle colors
  • ResetToggleColors()Reset toggle colors to default
  • ResetBorderColors()Reset border colors to default
  • GetFlag()Get flag value
  • SetFlag()Set flag value
  • Connection.FlagsChangedEvent fired when flag changes
  • Connection.FileSavedEvent fired when file is saved

🔸 Window (win)

  • MakeTab()Create a new tab
  • MakeTabGroup()Create a tab group with subtabs
  • Dialog()Create a confirmation dialog
  • Bar() / Bar2() ...Add badges to title bar
  • Set()Change window title/subtitle
  • CloseBtn()Close the window
  • MinimizeBtn()Minimize the window
  • SelectTab()Select tab by index or reference

🔹 Tab & SubTab

  • AddSection()Add a section header
  • AddButton()Add a button
  • AddToggle()Add a toggle switch
  • AddSlider()Add a numeric slider
  • AddTextBox()Add a text input box
  • AddDropdown()Add a dropdown selector
  • AddProfile()Add a profile card
  • AddSingleDiscordCard()Add a Discord server card
  • AddDiscordInvite()Add two Discord cards side by side
  • Enable() / Disable()Show/hide tab
  • Visible()Toggle visibility
  • Destroy()Remove tab

🔸 Element Methods (Common)

  • Set()Change value / title / description
  • Visible()Show/hide element
  • Destroy()Remove element
  • Callback()Trigger callback (if available)
